# Öffentlicher Preview-Schlüssel

`pmddcam-preview.keystore` ist ein absichtlich öffentlicher Entwicklungsschlüssel, kein Geheimnis. Passwort und Alias stehen in `app/build.gradle.kts`. Er dient ausschließlich kompatiblen Updates persönlicher Preview-Installationen. Nicht für eine Produktions- oder Play-Store-Veröffentlichung verwenden. Ein privater Produktionsschlüssel gehört nicht in dieses Repository.
